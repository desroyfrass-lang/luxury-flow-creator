FRASS-0422 — Security by Design. Constitutional.

No milestone is complete until all five audits are green:
1. Security Audit
2. Privacy Audit
3. Performance Audit
4. Accessibility Audit
5. Financial Audit (whenever money is involved)

**How to apply:** at the end of any major feature/district build, run the security scan, state the privacy posture (what data is exposed to whom), note performance impact, confirm accessibility basics (semantic HTML, alt text, keyboard/aria), and reconcile any money paths. Report the five as a checklist. Never declare a milestone done with an unrun or failing audit.

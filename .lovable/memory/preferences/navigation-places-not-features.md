Constitutional principle: **Navigation should expose Places. Not features. Features live inside places.**

Example: Health & Wellness Centre is one nav item that contains Wellness, Care Network, Herbal Garden, Meditation, Artist Wellness and Nutrition. One district, many services.

**How to apply:** when adding a new capability, first ask which existing place it belongs to. Only create a new top-level nav entry when the thing is genuinely a new place on Frass Hill. Reserve gold for luxury moments; chrome for interaction.

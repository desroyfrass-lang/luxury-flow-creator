# FRASS-0200 Amendment — Principles 13–15 (COMPLETE)

**Constitutional principle:** The Founder never edits production directly. The Founder edits the Blueprint.

## Principle 13 — Constitutional Change Governance & Architectural Memory
- Every approval requires Founder Intent ("What problem are we solving, and why is this change important?"), stored permanently with impact summary, credit forecast, registry reference and components modified.
- `architecturalMemory()` surfaces conflicts when a proposal reverses an earlier approved decision. Nothing is silently overwritten.

## Principle 14 — Regression Protection & Verification
- Each Blueprint declares expected behaviour (`EXPECTED_BEHAVIOUR` registry / `expectedBehaviour()`).
- Decision Records carry `verification: pending | verified | failed`, confirmed behaviour by behaviour in the Blueprint panel.

## Principle 15 — Continuous Architectural Integrity
- `architecturalIntegrityReview()` scans duplicate purposes, orphaned connections, untagged DOM components, unverified decisions and blueprint coverage.
- Surfaced as the **Architectural Health** panel on the Founder Dashboard. Reports only, never auto-corrects.
- **Truth Before Beauty** — no green light without a real connected signal; "unknown" is honest.

## Lifecycle
Vision → Blueprint → Simulation → Impact Report → Credit Forecast → Founder Intent → Founder Approval → Implementation → Verification → Version Archive → Architectural Memory → Continuous Integrity Review

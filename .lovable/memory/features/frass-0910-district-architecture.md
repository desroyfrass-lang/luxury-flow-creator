# FRASS-0910 — SUPERSEDED

The 12-district list in this spec listed **functions as districts**. It was corrected by
[FRASS-0920 Town Plan](mem://features/frass-0920-town-plan), which reduces Frass Hill to
eight real places, each containing venues.

Still in force from FRASS-0910:

## Terminology standard (constitutional)
- **Frass Builders** — anyone building a business, project or opportunity ON the platform.
- **Skilled Builders** — tradespeople who physically build communities.
- The bare word "Builder" is never used alone.

## The eight universal rules
Emotional identity · Functional purpose · Primary audience · Connected systems · Daily activity ·
Seasonal evolution · Community contribution · Legacy.

## District Stewards
Frassy adapts professional expertise per district while keeping one personality.
